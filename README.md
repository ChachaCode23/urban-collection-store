Urban Collection Store 
-----------------------------------------------------------------
Proyecto CRUD funcional desarrollado como parte de la asignatura Programacion 3, este simula el panel de administración de una tienda de ropa y accesorios urbanos.

Descripción del proyecto
-----------------------------------------------------------------
Urban Collection Store es una aplicación web sencilla que permite gestionar productos de una tienda, el sistema permite agregar, ver, editar y eliminar productos (CRUD) desde un panel de administración.
La tienda maneja productos como ropa, accesorios y perfumes.

Tecnologías usadas
-----------------------------------------------------------------
HTML5
CSS3
JavaScript (Vanilla)
Git y GitHub
Metodología Git Flow

Cómo correrlo
-----------------------------------------------------------------
Clonar el repositorio: git clone https://github.com/ChachaCode23/urban-collection-store.git
Abrir la carpeta del proyecto
Abrir el archivo index.html en el navegador

No necesita instalación ni servidor, corre directo en el navegador.

Flujo Git Flow
-----------------------------------------------------------------
Se aplicó la metodología Git Flow con las siguientes ramas:
main - rama principal con el código en producción
developer - rama de desarrollo
qa - rama de pruebas.

| Rama                   |             Descripción |
-----------------------------------------------------------------
 feature/login-form -----> Formulario de inicio de sesión 
 feature/validate-user-input -----> Validaciones de formularios 
 feature/payment-api-integration -----> Simulación de pagos 
 feature/user-dashboard -----> Panel de pedidos del usuario 
 hotfix/fix-date-format -----> Corrección del formato de fecha 

Cada rama generó 3 Pull Requests: uno hacia `developer`, uno hacia `qa` y uno hacia `main`. Total: 15 Pull Requests cerrados.
